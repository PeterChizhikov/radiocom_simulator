# Проект: анализ линии связи на SDR (Pluto SDR)

**Дата:** 2026-09-27
**Обновлено:** 2026-10-10

## Цель проекта

Система для имитации и анализа линии связи между базовой станцией и абонентом
(по мотивам LTE/5G NR), на базе двух SDR-платформ Pluto SDR, с собственным
упрощённым PHY и сетевым протоколом.

## Зафиксированные решения

| Параметр | Решение |
|---|---|
| Язык ядра DSP | C++ |
| Уровни системы | PHY + упрощённый сетевой протокол (подключение абонента к БС) |
| Дуплекс | TDD (время делится между приёмом и передачей на одной частоте) |
| Направление | Двустороннее (БС↔абонент) |
| Полезная нагрузка (пока) | Тестовые данные — текст/известный паттерн, без реального IP-трафика |
| UI | Веб-интерфейс |
| Первый этап тестирования | Два Pluto, подключённые к одному компьютеру, передача через эфир на малой мощности (без кабеля). Перед этим — проверка на одном Pluto (TX1 → RX1 через антенны) |
| Работа с SDR | libiio (C API) напрямую, без промежуточных библиотек |
| Частота для опытов | 2.4 ГГц (ISM) |
| Частота дискретизации (пока) | 3.84 MSPS |
| Мощность передачи | Начинать с минимальной, поднимать шагами по 10 дБ; ослабление TX не меньше 40 дБ (ограничено в коде) |
| Подход к развитию | Сначала простейшая проверка гипотезы, усложнение — по результатам опытов |

## Этапы

| Этап | Статус | Описание |
|---|---|---|
| 1. Передача и приём тона | Выполнен | Управление Pluto из C++, тон передан с одного Pluto на другой через эфир. Расхождение частот двух Pluto ≈ −11.9 кГц на 2.4 ГГц. Подробности — `sdr_txrx_test.md` |
| 2. OFDM-кадр через эфир | Следующий | Передать кадр из `SignalManipulation`; на приёме найти начало кадра и скомпенсировать сдвиг частоты |
