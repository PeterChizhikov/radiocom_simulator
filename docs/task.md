# Проект: анализ линии связи на SDR (Pluto SDR)

**Дата:** 2026-09-27

## Цель проекта

Система для имитации и анализа линии связи между базовой станцией и абонентом
(по мотивам LTE/5G NR), на базе двух SDR-платформ Pluto SDR, с собственным
упрощённым PHY и сетевым протоколом.

## Зафиксированные решения

| Параметр | Решение |
|---|---|
| Язык ядра DSP | C++ |
| Уровни системы | PHY + упрощённый сетевой протокол (подключение абонента к БС) |
| Дуплекс | TDD (время делится между приёмом и передачей на одной частоте) |
| Направление | Двустороннее (БС↔абонент) |
| Полезная нагрузка (пока) | Тестовые данные — текст/известный паттерн, без реального IP-трафика |
| UI | Веб-интерфейс |
| Первый этап тестирования | Один Pluto SDR, TX→RX через кабель с аттенюатором (без второго устройства и без эфира) — проверка PHY-тракта целиком |

## Открытые вопросы (пока не решены)

- Архитектура процессов: один процесс на оба Pluto или два отдельных (роль БС / роль абонента)
- Полоса частот, разнос поднесущих, структура кадра/слотов
- Конкретные библиотеки для LDPC/модуляции
- Диапазон частот для передачи по воздуху (когда перейдём к двум устройствам)
