# Этап 1: передача и приём тона через Pluto SDR

**Дата:** 2026-10-10

## Цель

Проверить базовую гипотезу: программа на C++ управляет Pluto SDR, передаёт сигнал в эфир и принимает его.
Сигнал — комплексный тон (одна линия в спектре), чтобы проверка не зависела от модуляции и синхронизации.

## Устройства

| URI (на момент опыта) | Чип в прошивке | Каналы | Серийный номер |
|---|---|---|---|
| `usb:1.2.5` | AD9364 | 1×1 | `10400090fd95000305003100182a1a57b2` |
| `usb:1.4.5` | AD9361 | 2×2 (данные в `pluto_info.md`) | `104000409f940014120037006ca8c6bcd2` |

URI зависит от USB-порта и может меняться после переподключения — проверять через `iio_info -s`.
Антенны: на `usb:1.2.5` — RX1, на `usb:1.4.5` — TX1, расстояние несколько сантиметров.

## Программа `radiocom_txrx`

```bash
./build/radiocom_txrx --tx <uri> [--rx <uri>] [--tx-atten <dB>] [--rx-gain <dB>] [--no-tx] [--output rx.iq] [-v]
```

| Параметр | Значение | Почему |
|---|---|---|
| Частота LO (TX и RX) | 2.4 ГГц | ISM-диапазон |
| Частота дискретизации | 3.84 MSPS | одна из двух, поддерживаемых буфером Pluto |
| Полоса аналогового фильтра | 3 МГц | чуть уже частоты дискретизации |
| Тон | +100 кГц от LO, амплитуда 0.5 | вдали от DC и краёв полосы, запас до перегрузки ЦАП |
| Буфер TX | 3840 отсчётов, циклический | ровно 100 периодов тона — без разрыва фазы на стыке |
| Приём | 65536 отсчётов | разрешение спектра 3.84 МГц / 65536 ≈ 59 Гц |
| Усиление RX | ручное (AGC выключен) | чтобы запуски были сопоставимы |

Вывод: уровень приёма (dBFS) с предупреждением о клиппинге и самый сильный пик в полосе (без ±10 кГц у DC):
частота, сдвиг от 100 кГц и превышение над медианой спектра (оценка шума). Принятые I/Q сохраняются в `rx.iq`
(float32 I/Q, как у `radiocom_sim`).

### Безопасность приёмного тракта

Повредить приёмник может только мощность на входе RX; усиление RX влияет лишь на клиппинг АЦП.

- При старте ослабление TX сначала ставится на максимум (89.75 дБ), затем остальные настройки.
- Ослабление меньше 40 дБ программа не принимает.
- При выходе передача останавливается, ослабление возвращается на максимум.
- Мощность поднимали шагами по 10 дБ от минимальной.

## Результаты

### Один Pluto (`usb:1.2.5`), антенны на TX1 и RX1, усиление RX 50 дБ

| Ослабление TX | Тон над шумом |
|---|---|
| без передачи | не виден |
| 80 дБ | 39.4 дБ |
| 70 дБ | 49.2 дБ |
| 60 дБ | 60.5 дБ |

Тон на 100 020 Гц — ближайший к 100 кГц бин, то есть сдвиг частоты ≈ 0: TX и RX работают от общего генератора.
Уровень растёт на ~10 дБ на каждые 10 дБ мощности.

Не проверено: шёл ли сигнал через антенны или через утечку TX→RX внутри платы (опыт без антенн не ставился).

### Два Pluto: TX `usb:1.4.5` → RX `usb:1.2.5`, усиление RX 50 дБ

| Ослабление TX | Пик | Над шумом |
|---|---|---|
| без передачи | 93 809 Гц (посторонний) | 31.0 дБ |
| 80 дБ | 93 809 Гц (посторонний) | 31.2 дБ |
| 70 дБ | 88 066 Гц | 32.7 дБ |
| 60 дБ | 88 066 Гц | 43.7 дБ, повтор 42.6 дБ |
| 50 дБ | 88 066 Гц | 54.0 дБ |

**Расхождение частот двух Pluto: −11.9 кГц на 2.4 ГГц (≈ −5 ppm)**, стабильно в пределах 59 Гц за несколько минут.
Это почти одна поднесущая OFDM-сетки симулятора (15 кГц) — на приёме его придётся оценивать и компенсировать.

Первая попытка (TX `usb:1.2.5` → RX `usb:1.4.5`) не дала сигнала: роли были перепутаны относительно антенн.

### Наблюдения

- На `usb:1.2.5` без передачи есть посторонний сигнал около +92…94 кГц (~31 дБ над шумом), частота плавает.
  Источник неизвестен.
- Через эфир между устройствами сигнал на ~17 дБ слабее, чем в опыте с одним Pluto, при той же мощности.

## Рабочая команда

```bash
./build/radiocom_txrx --tx usb:1.4.5 --rx usb:1.2.5 --tx-atten 60 --rx-gain 50
```

Тон ~43 дБ над шумом при очень малой мощности, клиппинга нет (максимум ~0.07 шкалы).

## Сборка: libiio на macOS

`/Library/Frameworks/iio.framework` (0.26) собран только под x86_64 и с arm64-программой не линкуется.
Используется arm64-сборка из Homebrew (`brew tap tfcollins/formulae && brew install libiio`,
`/opt/homebrew/Frameworks/iio.framework`, 0.23). Её `libiio.pc` указывает на несуществующий каталог,
поэтому CMake ищет библиотеку через `find_library`/`find_path`, а не pkg-config.
